# 2026-11-23

## Done

- Created the `Project-Articula` GitHub organisation and the public `articula`
  repository.
- Adopted **AGPL-3.0** for the whole project.
- Set up an AI maintainer account (`@articula-agent`) holding two least-privilege
  credentials: a read-only front-desk token (issues and comments) and an engineer
  token (code and pull requests). Neither can change repository settings or touch
  secrets.
- Protected `main`: changes must arrive through a pull request, and merging
  requires human approval. Verified by attempting a direct push (rejected) and by
  a probe pull request (merge blocked pending review).
- Added the project skeleton: licence, README, security policy, agent rules and
  this devlog.

## Learned

- Least privilege is testable rather than aspirational. Every claim in this entry
  is backed by a request that failed on purpose.

## Next

- Publish the first batch of design notes, edited for public reading.
- Draft the repository layout for the first implementation scaffold.

## Later that day

- Added `tools/frontdesk/`, a prototype triage bot for incoming issues: fixed
  action set (read, classify, write a local brief), no GitHub writes, security
  heuristics that never depend on the language model, optional CPU-only model
  summary, and a bubblewrap sandbox that hides the home directory.
- Added full Traditional Chinese editions of every public document; from now on
  a document without its counterpart is treated as a bug.
